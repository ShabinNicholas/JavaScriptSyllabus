# JavaScript Syllabus

Welcome! This is a friendly, hands-on JavaScript reference built to follow a complete syllabus — from your very first `let` to writing your own `class`.

Every page follows the same shape:

- **What it is** — a plain-English explanation, no jargon dumps.
- **Why it matters** — when you'd actually reach for this.
- **Code you can run** — short, heavily commented examples you can paste into a browser console or a `.js` file.
- **Try it yourself** — a tiny challenge to lock the concept in.

## How to use this site

Pick a topic from the sidebar, or follow the syllabus in order if you're learning JavaScript from scratch. The topics build on each other:

1. **Fundamentals** — variables, operators, conditionals, loops, functions.
2. **Arrays & Objects** — JavaScript's two core data structures.
3. **Browser & DOM** — making a page interactive.
4. **Errors & Async** — handling things that fail or take time.
5. **Strings, Scope & Modern JS** — sharper tools and ES6+ syntax.
6. **Modules, Data & OOP** — organizing bigger programs.
7. **Beyond the Browser** — a first look at Node.js.

## Running the examples

You don't need to install anything to follow along:

- Open your browser's DevTools console (`F12` or `Ctrl+Shift+I`) and paste code directly, **or**
- Save a snippet as `practice.js` and run it with Node.js: `node practice.js`
